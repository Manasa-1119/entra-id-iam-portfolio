# entra-id-iam-portfolio
Microsoft Entra ID and IAM hands-on labs, access management, authentication, and troubleshooting.

Overview:

This repository documents my hands-on practice with Microsoft Entra ID and Identity and Access Management (IAM) using a personal Microsoft 365 / Entra test tenant.

The portfolio focuses on identity lifecycle management, access control, authentication, application assignments, and log-based troubleshooting.

Lab Areas:

1. User and Group Management:

Created and managed test users.
Created security groups and managed group membership.
Verified membership changes through audit logs.

2. Role-Based Access Control:

Practiced assigning built-in Entra directory roles.
Reviewed role assignments and least-privilege principles.

3. MFA and Authentication:

Registered Microsoft Authenticator for a test account.
Verified successful sign-in activity.

4. Audit Logs and Sign-in Troubleshooting:

Investigated user and group change events.
Reviewed successful and failed sign-in attempts.
Examined failure details and error codes.

5. Joiner-Mover-Leaver (JML):

Joiner: created a test user and granted group access.
Mover: updated user properties and changed group membership.
Leaver: disabled the test account and examined sign-in results.

6. Guest User / B2B Access:

Invited an external test user.
Verified invitation acceptance and group membership.
Reviewed related audit events.

7. Enterprise Application Access:

Reviewed enterprise application settings.
Practiced configuring assignment requirements and direct user assignment.

Tools and Concepts:

Microsoft Entra admin center.
Microsoft 365 test tenant.
Identity lifecycle management.
RBAC and least privilege.
MFA and authentication.
Audit logs and sign-in logs.
Enterprise application access.

Scope and Limitations:

These are personal lab exercises, not production IAM implementations. Some premium capabilities, including certain Conditional Access and PIM scenarios, were studied conceptually because the required licensing was not available in the test tenant.

Learning Outcome:

This portfolio demonstrates foundational IAM administration, access management, identity lifecycle workflows, and troubleshooting using Microsoft Entra ID.
